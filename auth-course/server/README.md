# Node.js auth course (server)

## Описание
Курс по авторизации с jwt и email на Node.js.

Реализовал: Mongoose сущности User и Token;
Контроллер, роутер, Дто для авторизации;
Сервисы - авторизации, токена, mail;
middleware - для проверки авторизации и обработки ошибок;
exceptions - для кастомных ошибок;

## Стек
Node.js, express, nodemon, MongoDB, mongoose, bcryptjs, jsonwebtoken, JWT, nodemailer, cors, cookie-parser, uuid.

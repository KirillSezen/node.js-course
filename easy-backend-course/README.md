# Node.js easy backend course

## Описание
Простой курс по использованию Node.js совместно с нереляционной БД MongoDB.

Реализовал: Mongoose сущность Post;
Контроллер, сервис, роутер для Post;
FileService - для работы с изображениями Post;

## Стек
Node.js, express, nodemon, MongoDB, mongoose, uuid.

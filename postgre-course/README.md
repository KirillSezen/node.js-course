# Node.js - PostgreSQL course

## Описание
Курс по использованию Node.js совместно с реляционной БД PostgreSQL.

Реализовал: 2 таблицы (person и post);
Контролеры и роуты для сущностей (Posts и Users);
Простой CRUD для Users и создание, получение по id для Posts.

## Стек
Node.js, express, nodemon, dotenv, PostgreSQL, pg.

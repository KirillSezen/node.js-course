# Node.js easy auth course

## Описание
Простой курс по базовой авторизации с jwt на Node.js.

Реализовал: Mongoose сущности User и Role;
Контроллер, роутер для авторизации;
middleware - для проверки авторизации и роли;

## Стек
Node.js, express, nodemon, MongoDB, mongoose, bcryptjs, jsonwebtoken, JWT.
